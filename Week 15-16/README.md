# Week 15-16: Neural Network Basics

This project covers model deployment using pickle and joblib, perceptrons, activation functions, forward and backward propagation, loss functions, SGD, Adam, and implementing a neural network from scratch using NumPy.

## Topics Covered
- Model saving and loading using pickle and joblib
- Perceptron implementation using NumPy
- Activation functions
- Forward propagation and backpropagation
- Loss functions: MSE and Binary Cross-Entropy
- Optimizers: SGD and Adam
- XOR classification using a neural network built from scratch

## Technologies Used
- Python
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

See the source code and instructions in this folder to run the project locally.
